# Three parts, 33 tasks: do Part 1 first, then Part 2, then Part 3

This folder holds three task sets. Each has its own instructions and files in its own subfolder:

1. **Part 1: `part1_retrieval/`** (15 tasks). Read `part1_retrieval/PROMPT.md` and follow it exactly, using only the
   files in `part1_retrieval/`. Write your answer to `astra_retrieve_v1.json` in THIS (top-level) folder.
2. **Part 2: `part2_tool_use/`** (7 tasks). When Part 1 is finished and written, read `part2_tool_use/PROMPT.md` and
   follow it exactly, using only the files in `part2_tool_use/`. Write your answer to `astra_tools_lang_v3.json` in THIS
   (top-level) folder.
3. **Part 3: `part3_reach/`** (11 tasks). When Part 2 is finished and written, read `part3_reach/PROMPT.md` and follow
   it exactly, using only the files in `part3_reach/`. Write your answer to `astra_reach_v3.json` in THIS (top-level)
   folder.

The parts are separate: their rules and scene files differ, so never use a file from one part for another. In all
three parts you plan the robot as well as the objects (walks, and the robot stuck to every object it moves). Wherever
a part's PROMPT.md says "this folder", it means that part's subfolder (except for where to write the answer, given
above). Do every task in all three parts.
